# Examples

This folder is for **community-contributed** configs, prompt templates, and
usage patterns. It's kept separate from the core `server/` code so it's easy
to see what's officially maintained vs contributed.

Guidelines for contributions here:

- Keep examples generic and reusable — no proprietary, internal, or
  company-specific data.
- No secrets, tokens, or credentials, even fake-looking placeholders that
  could be mistaken for real ones — use obviously fake values like
  `sk-example-xxxxx` if a placeholder is needed.
- A short comment at the top of each file explaining what it demonstrates
  is appreciated.

See [../CONTRIBUTING.md](../CONTRIBUTING.md) for the full contribution flow.
